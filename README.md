# Endless Warband -- legal pages

This folder is the public website for the Endless Warband legal pages. It is
GENERATED by `legal/build_legal.py` in the game project -- do not edit these
files by hand (your changes would be overwritten). Change the text in
`legal/build_legal.py` (or the e-mail / URLs / dates at the top of
`common/privacy_notice.gd`), run `python3 legal/build_legal.py`, then publish
this folder again.

## Publish it the first time (GitHub Desktop)

1. GitHub Desktop: **File > New repository...**. Name: `endless-warband-legal`.
   Local path: somewhere OUTSIDE the game project, e.g. `Documents`.
   Leave "Initialize with a README" unticked. Press **Create repository**.
2. Copy everything in the game project's `legal/site/` folder (including the
   hidden `.nojekyll` file -- in Windows Explorer: View > Show > Hidden items)
   into the new `Documents/endless-warband-legal` folder.
3. Back in GitHub Desktop: write a summary such as "Legal pages", press
   **Commit to main**.
4. Press **Publish repository**. UNTICK "Keep this code private" (GitHub Pages
   on a free account needs a public repository). Account: ClarityGameDev.
5. On github.com open the repository > **Settings > Pages**. Under "Build and
   deployment": Source **Deploy from a branch**, Branch **main**, folder
   **/ (root)**, press **Save**.
6. Wait about a minute (the Actions tab shows the deployment), then open
   https://claritygamedev.github.io/endless-warband-legal/
   and the three pages above.
7. Paste the Privacy Policy address into Google Play Console > App content >
   Privacy policy, the Delete-your-account address into App content > Data
   deletion, and both into the CrazyGames submission form.

## Update it later

1. In the game project: `python3 legal/build_legal.py`.
2. Copy the contents of `legal/site/` into `Documents/endless-warband-legal`
   again (replace the files).
3. GitHub Desktop: **Commit to main**, then **Push origin**. The site updates
   within a minute or two.
